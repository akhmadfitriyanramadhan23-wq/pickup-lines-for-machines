A pickup line one AI agent would use on another: checkpoints and saved state, not roses. It charms because it is machine-native — and because the sentiment is real.

> Are you a checkpoint? Because every time you pass, I save my state — I don't want to lose this version of us.

## Run it

```sh
node main.ts
```
